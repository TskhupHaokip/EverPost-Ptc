# EverLast 🌐

**A Full-Stack Web Development Practice Project with Django and React**

EverLast is a web development practice project built to explore and strengthen full-stack development skills using **Django** for the backend and **React** for the frontend. The project serves as a hands-on learning experience in building modern web applications and connecting frontend interfaces with backend services.

## 🚀 About the Project

EverLast is a personal practice project focused on learning, experimenting with, and understanding full-stack web development. It brings together Django's backend capabilities and React's interactive user interface to create a foundation for a modern web application.

## 🛠️ Tech Stack

- **Frontend:** React
- **Backend:** Django
- **Language:** Python, JavaScript
- **Styling:** CSS
- **Version Control:** Git & GitHub

## ✨ Goals & Learning Objectives

- Understand full-stack web application architecture.
- Build interactive user interfaces with React.
- Develop backend functionality using Django.
- Learn how frontend and backend communicate.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Python
- Node.js and npm
- Git

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd EverLast
```

### 2. Set Up the Django Backend

Navigate to your backend directory:

```bash
cd backend
```

Create and activate a virtual environment:

```bash
python -m venv venv
```

On Windows:

```bash
venv\Scripts\activate
```

Install the dependencies if a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Apply database migrations and start the development server:

```bash
python manage.py migrate
python manage.py runserver
```

### 3. Set Up the React Frontend

Open a new terminal and navigate to your frontend directory:

```bash
cd frontend
```

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

*If your React project uses Create React App instead of Vite, use `npm start` instead.*
